# 星座の軌跡 — 35の戦時の証

架空の世界を生きた35人の証言を、星座の地図としてたどるインタラクティブな作品。
**星＝人 / 線＝その人が歩いた道 / 交差＝時を越えて同じ場所に立った者たち。**
星に触れて、物語を読む。

→ https://tama831.github.io/seiza-no-kiseki/

**デザイン: 青写真の星図 (Cyanotype Archive)** — 戦争の記録をシアノタイプ（青焼き）の感光紙として扱う。
プルシアンブルーに沈んだ世界の上を、人が歩いた跡だけが白く感光して残る。読むという行為が露光であり、
触れた星から先へ足跡が一筋ずつ焼きつけられていく。死者は白く定着したのち、ゆっくり赤錆へ酸化して止まる。
**人物図鑑**: 物語ヘッダの語り手名にマウスを乗せると肖像figureが感光し、クリックで図版+人物解説が開く。
肖像は時代でメディアが進化する — 銅版図版(古代〜中世) → 青焼き写真(近世〜近代) → スキャン(未来: 琥珀の野帳/シアンのデータ層)。

> ⚠️ 戦争の暴力（占領・処刑・飢餓・身体の損壊・子どもの死など）を直接描く場面を含みます。美化や煽情を避け、起きたことを起きたままに描いています。
